## 🎮 THE DEVELOPER

**전력을 나누고, 몰려오는 적을 막아라.**

제한된 전력 안에서 터렛을 운영하고, 직접 전투에 뛰어드는 전략 디펜스 게임입니다.

어디에 전력을 집중할지 판단하며 몰려오는 위협에 대응하세요.

## 개발 중 필요한 도구를 직접 만듭니다.

도구를 만들고, 배운 것을 기록하고, 새로운 이야기를 나눕니다.

<br>

### 🧵 Threadle

GitHub 관련 소식을 Discord로 전달하고, 소식별 스레드에서 팀원들과 이야기를 이어갈 수 있도록 돕는 도구입니다.

새로운 소식을 확인하는 것부터 의견을 나누는 과정까지 연결합니다.

[Threadle 알아보기](https://threadle.teamhjd.com/)

<br>

---

### 🎨 PixelPin

화면의 색상을 빠르게 확인하는 Windows 컬러 피커입니다.

[PixelPin 알아보기](https://pixelpin.teamhjd.com/)

<br>

---

### 🚀 Game Test Launcher

TeamHJD 자체 게임의 테스트 빌드를 배포하고, 실행 테스트를 진행하기 위한 런처입니다.

[Game Test Launcher 알아보기](https://testlauncher.teamhjd.com/)

<br>
